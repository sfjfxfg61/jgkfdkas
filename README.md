# Victoria Simple v3.1 — названия тарифов и тексты

**Назначение:** технический шаблон подписки на обычное сообщество в Telegram. Не включает контент с возрастными ограничениями и не проверяет возраст. Для возрастных материалов его нельзя использовать без соответствующих ограничений, модерации и проверки требований Telegram и применимых правил.

## Что делает

1. `/start`: одна кнопка приглашения в публичный канал **по языку**, три прямые кнопки Stars и короткое меню. Подписка на публичный канал не обязательная.
2. **Три тарифа:** Проверка (7 дней), Безлимит навсегда, VIP (доступ + личный чат, 30 дней). Ручная переписка идёт через прежнюю систему обращений админу, отдельный Telegram-чат не создаётся. Покупки разовые, автопродления нет. Подтверждение и пополнение Stars выполняет сам Telegram.
3. **Цены по регионам** в существующем поле `users.market`. UA/CIS/LATAM/ASIA: `100 / 250 / 500` Stars; EU/US/GLOBAL: `250 / 500 / 1000` Stars. Для изменения по регионам можно добавить `PRICE_MATRIX_JSON` (необязательно).
4. **Платежи и доступ:** только подтверждённый `successful_payment` сохраняется в `payments` и открывает приватный канал. Инвайт в платный канал действует 12 часов, заявки на вступление проверяются по статусу подписки.
5. **Напоминания:** по одному в сутки с переменным временем в пределах **18:00–21:00 Europe/Kyiv**. Для людей, ранее запустивших бота, с доступной перепиской, включая покупателей с действующим Premium, если не отключили уведомления в меню. Время для каждого пользователя отличается и меняется по дням. Если сервис проснулся позже выбранной минуты, бот пытается отправить сообщение при следующей проверке в этот же день (после 18:00); при недоступном сервере и Telegram доставка не гарантирована. Отключение уведомлений остаётся доступно через раздел «Напоминания» в меню. Текст не утверждает, что ссылка исчезнет.
6. **Админка:** `/admin`, `/stats`, `/pending`, `/payments`, `/regions`, `/funnel`, `/reminder_stats`, `/user ID`, `/messages ID`, `/send ID текст`, `/repair` и `/cancel_legacy_jobs`.
7. Нет сценариев общения, чат-ботов с ИИ, обязательного гейта, дополнительных тарифов, нового хранилища или миграций SQL.

## Что сделать для запуска

1. **Supabase:** ничего не выполнять. Используются существующие таблицы `users`, `payments`, `events`, `pending_replies`, `messages`. Сделай резервную копию перед переходом. Старые платные записи в `users` **не стираются**, а ранее приобретённые доступы в 2099 остаются. Импорт SQL пользователей **не повторять**.
2. **GitHub:** загрузить **содержимое** этой папки в корень текущего репозитория. В корне должны быть `Dockerfile`, `main.py`, `config.py` и остальные файлы; не оставлять дополнительную вложенную папку.
3. **Render → Environment**: оставить существующие переменные `BOT_TOKEN`, `ADMIN_ID`, `SUPABASE_URL`, `SUPABASE_KEY`, `PRIVATE_CHANNEL_URL` (числовой ID), `PORT=8080`, `FOLLOWUPS_ENABLED=true`, `PUB_LINK_DE`, `PUB_LINK_EN`, `PUB_LINK_ES`, `PUB_LINK_FR`, `PUB_LINK_RU`, `PUB_LINK_UK`. **Ничего нового добавлять не обязательно**, если устраивает время 18:00–21:00 Kyiv и цены по умолчанию. `REMINDER_TIME=20:00` в v3 не используется (можно оставить, но он не влияет на расписание).
4. При желании поменять вечернее окно, ДОБАВИТЬ в Render:
   `REMINDER_WINDOW_START=18:00`, `REMINDER_WINDOW_END=21:00`, `REMINDER_TIMEZONE=Europe/Kyiv`. Старые `PUB_LINK_*` снова используются. Это могут быть числовые ID `-100...`, `@username` либо `https://t.me/...`.
5. Бот должен быть **администратором приватного канала** с разрешением приглашать (и удалять, если `REMOVE_EXPIRED=true`). Для **числовых** ID публичных каналов бот также должен иметь разрешение создавать приглашения. Если нужных прав нет, кнопка приглашения в конкретный публичный канал пропускается, сам `/start` и продажа продолжают работать.
6. **Render Deploy**: разворачивать только одну инстанцию с одним токеном. Сохраняем текущие настройки Docker Web Service, UptimeRobot/health-check `GET /health`. Если Render засыпает, доставка напоминаний может быть задержана.
7. **До переключения основного бота:** проверить на отдельном тестовом боте `/start`, кнопки публичных каналов, прямые ссылки Stars, получение и сохранение `successful_payment`, приглашение, вход, выключение уведомлений через меню, `/send ID`, админ-панель. Для проверки денег нужна настоящая Telegram test environment с тестовыми ресурсами. Код локально не подтверждает успешную оплату в production.

## Региональные цены

Устанавливаются в `catalog.py` как значения по умолчанию. Для изменения без GitHub добавить `PRICE_MATRIX_JSON`, например:

```json
{"ua":{"trial":100,"forever":250,"vip":500},"eu":{"trial":250,"forever":500,"vip":1000}}
```

Для каждой переопределяемой строки нужны **все три** цены. Время действия созданного подписанного счёта — 24 часа.

## Как работает ежедневное расписание

Для каждой даты и Telegram ID вычисляется постоянная случайно распределённая минута между `REMINDER_WINDOW_START` и `REMINDER_WINDOW_END`; это позволяет переживать рестарт без отдельной очереди. Состояние фактической отправки хранится в `users.last_reminder_at`. Отключение через меню уведомлений — `users.automation_paused=true`. Историческое `proactive_enabled` больше не требуется для получения уведомлений. Пользователи, заблокировавшие бота или не начавшие с ним чат, не получат сообщение из-за ограничений Telegram. Пользователи с действующим Premium также получают ежедневное уведомление, если не отключили его в меню.

## Техническая проверка

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest -q
python main.py
```

Никаких приватных токенов или SQL-дампов пользователей в архиве нет. Не загружай их в GitHub. Этот архив не проходил живое тестирование с твоим Render, Supabase и Telegram.

## Изменения v3.1

- Переименованы три тарифа в тексте, кнопках Stars и счетах во всех 6 языках.
- Команда `/stop` убрана, в клиентских текстах она не упоминается. Отключение уведомлений по выбору пользователя доступно через раздел «Напоминания» в меню.
- Цены, регионы, расписание, схема Supabase, env Render и роли админки не менялись.
- Название VIP обозначает ручную переписку через бота с администратором, отдельного личного Telegram-чата в коде нет. Покупателю не следует обещать иной формат, пока он не реализован.

## Изменения v3.2

- Исключение платных пользователей из ежедневных уведомлений снято. Напоминания могут получать как бесплатные, так и платные пользователи, если бот доступен и пользователь не отключил уведомления.
- Тексты уведомлений в `words.py`, расписание, региональные цены, тарифы, админка и схема Supabase остались без изменений.
