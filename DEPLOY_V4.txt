Victoria v4 — GLOBAL REACTIVATION

What changed
------------
1. Users do NOT need to open the tariff/paywall to enter the follow-up system.
2. New free users: 6h -> 24h -> 48h -> every 24h.
3. Existing free, unblocked, non-paused users older than 48h are automatically seeded after deploy.
   Their first global reminder is staggered over roughly 5-60 minutes, then every 24h.
4. If a user opens the paywall, the cold chain stops and the existing offer chain takes over:
   12h -> 48h -> daily.
5. If a user creates checkout, the checkout chain takes over:
   5m -> 30m -> 3h -> 12h -> 23h -> daily.
6. Successful payment / block / automation_paused stops sales reminders.
7. All reminder text uses users.lang: uk / ru / en / de / fr / es.
8. Existing tariffs, prices, Stars payments, admin inbox, calls and access logic are unchanged.

Render
------
AUTO_REPLY_AI=false

SUPABASE_KEY must be server-side service_role / sb_secret_, not anon / sb_publishable_.

Database
--------
Run HOTFIX_QUEUE_V4.sql once before deploy. It is safe to run again if the v3 queue hotfix
was already installed. It does not delete users or payments.
